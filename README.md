# Rompetorres: Galactic

Estrategia por cartas estilo Clash Royale con aventura roguelite: Resistencia, Voltempire, Azorks y Cazarrecompensas.
El juego está en `www/` (`index.html` + `game.js` + paquetes de imágenes `art_*.js`).

Cada vez que se sube un cambio a `main`, GitHub compila la APK de Android automáticamente:
pestaña **Releases** → descarga `Rompetorres-Galactic.apk` en el móvil e instálala.
